========================================
 碧蓝航线立绘导出器  v1.13.0
========================================

【这是什么】
把原来需要 AssetStudioMod、AzurLanePaintingExtract、ALPA 三个软件的流程，
合并成一个程序：直接读取游戏 AssetBundles，一步导出完整静态立绘 + 差分表情，
并且可以像 ALPA 一样自己挑要导出的表情。

【怎么用】
1. 双击 AzurLanePaintingExport.exe
   （第一次打开时两个路径都是空的，选择一次后会自动记住）
2. “素材根目录”选择游戏的 AssetBundles 文件夹
   （里面能看到 painting、paintingface、dependencies）
3. “导出目录”选择保存位置
4. 左侧勾选要导出的立绘（可搜索，例如 2b、hailunna）
5. 点“开始导出”

【差分表情自选】
· 选中一个立绘后，右侧“差分表情”会列出 0、1、2… 的缩略图
· 0 号 = 无表情底图，默认勾选；勾 1/2/3 才会导出对应表情
· 单击某个表情：上方大图立即合成，方便对比
· 勾选哪些：导出时就只出哪几个；都不勾则按底图处理
· 不再有“合并差分表情”总开关，表情完全由勾选决定
· “应用到全部”：把当前勾选套用到所有立绘（例如只勾 3 号）
· 没有对应表情的立绘会自动跳过表情部分，不会报错

【预览缩放】（v1.2）
· 滚轮缩放，按住左键拖动平移
· 也可以点 + / − / 1:1 / 适应，双击在 1:1 和适应窗口之间切换
· 放大后看差分表情细节更清楚

【表情偏移】（v1.5）
· 表情缩略图下方新增“横向偏移 / 纵向偏移”，可点上下箭头或直接输入数值
· 正数：横向=向右，纵向=向上（与 ALPA 一致）
· “恢复默认”把当前立绘的偏移归零；偏移会用于预览和导出

【界面说明】（v1.4）
· 日志移到底部状态栏，单行滚动，可直接选中复制
· 导出选项移到左侧列表下方，预览区更大
· 差分列直接显示表情数量（— 表示没有）
· 列表只保留名称和差分数量，状态用颜色表示（绿=完成、红=失败）
· 右上角“已选 x/y 项”显示勾选数量
· PNG 压缩默认 0（不压缩，保存最快）
· 0 号就是底图；不需要底图时把 0 取消勾选即可
· 帮助 → 查看日志 可打开完整日志并复制

【只看已勾选】（v1.2）
· 工具条“已勾选”按钮：只显示当前勾选的立绘，再点恢复
· 挑完图后可以用它快速核对清单，不用翻页找

【导出当前预览】（v1.2）
· 没有勾选任何立绘时点“开始导出”，直接导出当前预览的那一个
· 不再弹“是否导出前 200 项”的提示

【输出】（统一放进同名子文件夹，默认一个表情=一张图）
  导出目录\2b\2b_3.png           带 3 号差分表情的完整立绘
  导出目录\2b\2b.png             无表情底图（勾选 0 号时才有）
  导出目录\2b\parts\2B_rw.png   （勾选“同时导出各部件”时才有）

【v1.13 新增】
· 列表上新增“显示和谐版本 / 隐藏和谐版本”按钮：默认隐藏文件名带 _hx / _n_hx / _buildhx / _shophx 的皮肤
· 导出选项新增“导出和谐版本”（默认关闭）：不勾时跳过 _buildhx / _shophx 这类和谐遮挡层
  （例如 gezi_n 那两块 NOT ABLE TO DISPLAY 贴纸不会再被合进去，画布也不会被撑高 43 像素）
· 列表排序改成按皮肤分组：同一皮肤的 _n / _hx / _n_hx / _buildhx / _shophx 版本紧挨着排，
  顺序为 原版 → _n → _hx → _n_hx；皮肤序号按数值比较（_2 排在 _10 前）
  （_h 是婚纱版本，算独立皮肤，不并入同一组）
· 搜索框右侧新增“×”按钮：输入文字后才出现，点一下清空关键词并恢复全部列表

【v1.12.2 修正】
· 修复差分表情整体下沉 1 像素（a2_2 / qiabayefu_5 / kashan_2 等放大后能看到的横向接缝）
· 以前为个别立绘手动加过的纵向偏移会变得偏高 1 像素，点“恢复默认”即可

【v1.12.1 修正】
· 修复 1.12.0 打开后长时间不出窗口的问题（列表载入时误做了表情校验，全量要 97 秒；现在 1 秒内打开）

【v1.12 修正】
· 修复差分表情取错表情包：三段式名字（如 tiancheng_cv_2 / tiancheng_cv_3 / tiancheng_cv_h）原来全都取了
  同一个表情包，合成后脸是别人的、还会出现矩形接缝
· 现在优先用同名表情包；_n（无装备）仍与本体共用；_hx 有独立表情组时用自己的
· 回退到同图变体（_ex / _asmr / _wjz 等）时会先核对表情槽尺寸，确认对不上才不套用——
  宁可这张图没表情，也不贴错人的脸（目前只有 4 个黑化/剪影版命中）

【v1.11 调整】
· 分辨率默认改为“游戏布局”（如 4299×3779，人物层 1:1），下拉只显示“原始纹理 / 游戏布局”
· 修复 i404 / i404_n 等个别立绘合成错位（画面碎成几块）
· 画布尺寸吸附到纹理尺寸（2b 由 2048×1801 修正为 2048×1800）；图层与纹理尺寸一致时原样贴合，不再重采样
· 预览不再降采样，1:1 就是真实像素
· 纵向表情偏移在导出时和预览方向一致了（正数向上）
· 导出只解码用到的表情，批量导出更快
· 选到无效目录会立即清空列表，不会拿旧列表去导出

【建议】
· 第一次先勾 2~3 个立绘试导出，确认效果后再批量。
· “跳过已存在的文件”默认开启：只跳过已经存在的单个文件，缺哪个补哪个。
  例如先导了底图、后来勾了 1 号，再导出会自动补 2b_1.png。
· 想只要人物本体，可在筛选里选“仅 _rw”。
· 分辨率可选：“游戏布局”（默认，如 4299×3779，人物层 1:1）或“原始纹理”（如 2048×1800）。
  游戏布局的背景是上采样；要素材原生像素就切到“原始纹理”。
· 若某张图少了一两层装饰，检查素材目录里 ui\commonui_atlas 是否还在。
· 成品图里人物比背景略“软”是正常的：人物层按游戏布局比例合成（2b 为 1774→845px）。
  需要人物层的 1:1 原图，勾“同时导出各部件”，parts\2B_rw.png 就是 1774×2048 原始尺寸。

【常用问题】
· 提示“该文件不是立绘 prefab”：painting 目录里混有贴图 bundle，跳过即可。
· 导出很慢：把“并行”调大（内存 8G 建议不超过 6）。
· 杀毒误报：程序由 PyInstaller 打包，源码在“源码”文件夹，可自行构建。
